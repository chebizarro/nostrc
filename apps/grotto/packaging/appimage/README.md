# Grotto AppImage — experimental / deferred

`nostrc-h3kh` (Groundhog AppImage bundling GUI, daemon and GStreamer) remains
open and deferred. A changing AppImage mount path cannot be treated as an
attested installed approver. Launch-on-login is unsupported for this format.
The desktop file here is not the canonical native desktop asset.

Before release, prove all §5.11 signer gates: host caller attestation, trusted
approver identification, Secret-portal custody, activation ownership and
browser-host behavior. See [Flatpak gate details](../flatpak/README.md).
Do not bypass path/device/inode checks, fall back to an unverified caller or
claim that a bundle launch is signing acceptance. Native packages remain primary.
