Schema: org.gnostr.Key
Attributes:
- type=nostr-key
- npub=<npub1...>
- uid=<friendly identity label>
- curve=secp256k1
- origin=software|hardware
- hardware_slot=<token-specific locator, optional>

Label format shown in Seahorse (gnostr_secret_store_build_label):
  "Nostr key: <uid> (npub1xxxxxxxx…)"   when uid is set
  "Nostr key: npub1xxxxxxxx…"           when uid is empty
The npub is abbreviated to "npub1" + 8 chars in the label; the full npub is
always in the npub attribute.

Secrets:
- Software keys: store the private key material (hex or nsec) as the item secret
- Hardware keys: do not store private material; store a small reference and set origin=hardware
